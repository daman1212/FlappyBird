# 🐦 Neon Bird — Flappy Bird Remake

A modern cyberpunk remake of the classic Flappy Bird game, built with pure HTML5 Canvas and JavaScript. No libraries, no frameworks — just vanilla code.

## 🎮 How to Play
- Press SPACE or click/tap the screen to make the bird flap
- Fly through the neon pipes without hitting them
- Each pipe you pass = 1 point
- The game gets harder as your score goes up

## 🛠️ How I Built It
I built this entirely from scratch using:
- HTML5 Canvas for all the graphics and animations
- Vanilla JavaScript for the game logic (gravity, collision detection, scoring)
- CSS for the layout and UI screens

The bird, pipes, city skyline, and stars are all drawn with code — no images used at all. I coded the physics myself including gravity, jump velocity, and collision boxes. The game is fully responsive and works on both desktop and mobile.

## ✨ Features
- Cyberpunk neon city background with glowing buildings
- Animated bird with wing flapping and trail effect
- Particle explosions on death and scoring
- Best score saved in browser localStorage
- Medal system based on your score
- Fully mobile friendly — tap anywhere to flap
- Desktop version shows a side panel with score and controls
